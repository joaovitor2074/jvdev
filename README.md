## Sobre o projeto

Aplicação responsiva criada para apresentar minha experiência, tecnologias e projetos de forma visual e objetiva.

O portfólio destaca soluções reais em SaaS, sistemas institucionais, automações, painéis administrativos, cardápios digitais e integrações com APIs.

## Funcionalidades

- Apresentação profissional e resumo de experiência
- Catálogo de projetos com páginas detalhadas e galerias
- Seção de tecnologias e competências
- Elementos 3D interativos
- Animações e transições de interface
- Formulário de contato
- Layout responsivo para desktop e dispositivos móveis
- Otimizações de imagens e carregamento de efeitos visuais

## Tecnologias

- React
- Vite
- JavaScript
- React Router
- Tailwind CSS
- Framer Motion
- Three.js e React Three Fiber
- tsParticles
- EmailJS
- Vercel

## Projetos em destaque

- **Servix:** SaaS para gestão de clientes, orçamentos, ordens de serviço e financeiro
- **GIEPI:** sistema institucional com scraping, governança e divulgação de dados acadêmicos
- **Código TCC:** assistente para organização de trabalhos acadêmicos
- **Cardápios digitais:** experiências comerciais para delivery, QR Code e WhatsApp

## Como executar

```bash
npm install
npm run dev
```

Para validar a qualidade do código e gerar a versão de produção:

```bash
npm run lint
npm run build
```

## Estrutura

```text
src/
├── components/   # componentes visuais e seções
├── data/         # projetos e tecnologias
├── pages/        # páginas da aplicação
├── services/     # integrações
└── styles/       # estilos globais e por página
```
